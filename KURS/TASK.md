3. Исходные данные к проекту


Общие требования к приложению:  
Целью работы является разработка программы для автономного необитаемого подводного аппарата (АНПА) в симуляторе MUR IDE, реализующей движение по заданному набору путевых точек (waypoints) с возможностью визуализации пройденной траектории и сохранения данных для последующего анализа.
    - Программа должна функционировать в среде симулятора MUR IDE с использованием библиотеки pymurapi для взаимодействия с аппаратом. Разработка ведется на языке Python. Программа должна обеспечивать движение по заранее заданному списку координат (x, y, глубина), которые могут быть определены в коде или загружены из внешнего файла.
    - Управление движением реализуется с помощью простых пропорциональных регуляторов для курса и глубины. Должна быть предусмотрена визуализация траектории (вывод координат в консоль или сохранение в файл) с возможностью построения графика после завершения миссии.
   Функциональные требования к приложению:
    - Модуль задания путевых точек:
Хранение списка целевых точек в формате (x, y, z) или (x, y, глубина). Возможность задания точек непосредственно в коде программы в виде массива. Опционально: загрузка точек из текстового файла (CSV или TXT) с координатами. Возможность задания количества циклов прохождения по точкам.
    - Модуль навигации и расчета целевых параметров:
Определение текущих координат аппарата (доступно через API симулятора). Расчет расстояния до текущей целевой точки по формуле евклидова расстояния. Расчет целевого курса на основе разницы координат с использованием функции арктангенса. Логика переключения на следующую точку при достижении текущей (расстояние меньше заданного порога, например 0.5 метра).
    - Модуль управления движением:
Реализация простого пропорционального регулятора курса: управляющий сигнал пропорционален ошибке по курсу. Реализация простого регулятора глубины: управление вертикальными движителями для достижения целевой глубины. Постоянное движение вперед (задание средней мощности движителей) при наличии отклонения по курсу. Ограничение управляющих сигналов в пределах допустимых значений.
    - Модуль логирования:
Запись текущих координат через равные промежутки времени (например, каждую секунду). Сохранение данных в CSV-файл с колонками: время, координата X, координата Y, глубина, курс, расстояние до цели. Логирование моментов достижения целевых точек.
    - Модуль визуализации:
Вывод в консоль текущего положения, текущей целевой точки, расстояния до цели и текущего курса. Построение графика пройденной траектории после завершения миссии с использованием библиотеки matplotlib. На графике отображаются: реальная траектория (линия), заданные путевые точки (маркеры), моменты достижения точек (отметки).
    - Дополнительно (опционально):
Возможность построения траектории в реальном времени (обновление графика по мере движения). Сохранение нескольких графиков для разных миссий. Сравнение заданной и реальной траекторий.
