================================================================================
0. ОБЩАЯ ПОДГОТОВКА (один раз)
================================================================================

Что нужно на компьютере:
— MUR IDE (запускается, открывается проект с mur_ide и mur_simulator);
— Python с matplotlib (для графиков 4.22–4.25 и рис. В.2–В.3);
— редактор текста / Excel для CSV.

Каталог сценария:
  mur_ide/resources/examples/waypoint_mission/

Перед каждым прогоном в симуляторе:
1. Запустить симулятор (сцена бассейна, MiddleAUV).
2. В меню симулятора включить Remote mode (Ctrl+M).
3. В MUR IDE открыть waypoint_mission.py и запустить скрипт (Local).
4. Дождаться окончания миссии — в папке waypoint_mission/logs/ появится CSV:
   trajectory_log_ГГГГММДД_ЧЧММСС.csv

Скриншоты:
— macOS: Cmd+Shift+4 (область) или Cmd+Shift+5;
— Windows: Win+Shift+S;
— сохраняйте в KURS/screenshots/ с именами по номеру рисунка, например 4.05_прямая_старт.png

Графики:
— из Python (visualize.py) или готовые файлы в KURS/output/ (плакаты А4/А1).

================================================================================
РАЗДЕЛ 4. ИСПЫТАНИЯ (рисунки 4.1–4.21 — скриншоты)
================================================================================

Для каждого сценария создайте отдельный waypoints.csv в каталоге waypoint_mission
(или переименовывайте файлы между прогонами). Формат:

  X,Y,Z
  x1,y1,z1
  x2,y2,z2
  ...

Глубина Z — в метрах, положительная вниз (как в симуляторе), для тестов обычно 1…3 м.
Координаты X,Y — в плоскости сцены, в пределах примерно ±15…20 м от старта.

Примеры маршрутов (подстройте под вашу сцену):

Прямая (тест 2, рис. 4.5–4.8):
  0,0,2
  5,0,2
  10,0,2

Квадрат (тест 3, рис. 4.9–4.14) — можно взять текущий waypoints.csv в репозитории:
  0,0,1
  0.4,0,1
  0.4,0.4,1
  0,0.4,1
  (масштаб увеличьте до ~5–10 м, если аппарат «ходит в куче»)

Треугольник (тест 4, рис. 4.15–4.18):
  0,0,2
  6,0,2
  3,5,2

Ломаная (тест 5, рис. 4.19–4.21):
  0,0,2
  4,0,2
  4,3,2
  1,5,2
  6,1,2

РАЗДЕЛ 4. ГРАФИКИ ТРАЕКТОРИЙ (рис. 4.22–4.25) — из своих логов
==============================================================================

Нужен лог CSV после каждого сценария и список waypoints того же маршрута.

Способ А — скрипт visualize.py (рекомендуется)

В терминале:
  cd "/Users/roman/Documents/MUR IDE/mur_ide/resources/examples/waypoint_mission"
  python3 -c "
from pathlib import Path
from visualize import plot_trajectory, plot_depth_over_time
from waypoints import load_waypoints_from_csv

log = Path('logs/trajectory_log_XXXXXX.csv')   # подставьте имя файла
wp = load_waypoints_from_csv('waypoints.csv')  # тот CSV, с которым гоняли
plot_trajectory(log, wp, 'рис_4_22_прямая.png')
plot_depth_over_time(log, 'рис_4_22_глубина.png')
"

Повторите для четырёх прогонов → файлы для 4.22, 4.23, 4.24, 4.25.

Способ Б — интерактивно в Python

  python3
  >>> from visualize import plot_trajectory
  >>> from waypoints import load_waypoints_from_csv
  >>> wp = load_waypoints_from_csv("waypoints.csv")
  >>> plot_trajectory("logs/имя_лога.csv", wp, "trajectory_plot.png")

На графике должны быть:
— синяя сплошная — факт (из лога);
— красные точки — waypoints;
— красный пунктир — ломаная между точками.

Если траектория «уезжает» от эталона — подстройте ODOMETRY_SPEED_SCALE в odometry.py и повторите прогон.

Готовый плакат (все 4 маршрута на одном листе):
— KURS/output/04_графики_траекторий_A1.png — можно использовать для защиты;
— для рис. 4.22–4.25 в тексте лучше четыре отдельных PNG или нарезать с плаката.

Таблица 4.1 — показатели RMSE (без рисунка или как таблица в Word)
------------------------------------------------------------------------------
1. Для каждого лога посчитайте RMSE между точками (X,Y) из CSV и эталонной ломаной
   (ближайшая точка на отрезках между waypoints — см. формулу в ПЗ, п. 4.2).
2. Заполните столбцы в ПЗ: RMSE, max/min отклонение, при желании время миссии (последняя «Время» в логе).
3. Можно упрощённо: Excel, сравнение графика с эталоном «на глаз» + одна цифра RMSE из скрипта.
