Курсовой проект: траектория АНПА по точкам в MUR IDE (KURS)

Исходники отчёта (редактировать):
  ПЗ.txt      — пояснительная записка
  ПЗ_А.txt    — приложение А, руководство пользователя
  ПЗ_Б.txt    — приложение Б, программный код
  ПЗ_В.txt    — приложение В, результаты экспериментов

Конвертация из markdown (если правили .md):
  python3 KURS/md_to_txt.py

Сборка Word:
  python3 KURS/build_docx.py
  → KURS/docx/ПЗ.docx, ПЗ_А.docx, ПЗ_Б.docx, ПЗ_В.docx, ПЗ_полная.docx

Графика: KURS/output/
Как сделать каждый рисунок: KURS/ИНСТРУКЦИЯ_РИСУНКИ.txt
