ПРИМЕРЫ СБОРКИ УЧЕБНЫХ СЦЕН


1. Общие сведения

В MUR_Object_Library/Examples/ лежат три готовых полигона из объектов библиотеки. Они использовались при апробации (раздел 4 пояснительной записки) и могут служить образцом для своих сцен.

Открытие выполняется через Scene → Open в симуляторе с выбором нужного .mur_scene.


2. Пример 1 — Курс маркеров

Файл: example_markers_course.mur_scene

Назначение: последовательное прохождение точек маршрута, ориентирование по цвету.

Состав сцены:

Старт — красный куб 0,5 м, x = -4.
Waypoint 1 — жёлтый цилиндр, x = -2.
Waypoint 2 — синий цилиндр, x = 0.
Waypoint 3 — оранжевый цилиндр, x = 2.
Финиш — зелёная сфера, x = 4.
Линия трассы — белая разметка вдоль оси X.

Типовое задание: в Remote mode проплыть от красного куба к зелёной сфере с заходом на каждый промежуточный маркер.

Рисунок В.1 – example_markers_course, вид сверху (скриншот симулятора при оформлении).


3. Пример 2 — Полоса препятствий

Файл: example_obstacle_lane.mur_scene

Назначение: облёт стойки и балки, проход между стойками ворот.

Состав:

Красная стойка — цилиндр, h ≈ 2,5 м.
Горизонтальная балка — Box 3 м.
Ворота — две стойки и перекладина, проём ≈ 2,5 м.

Типовое задание: обойти стойку, пройти под балкой с запасом по глубине, пролететь между стойками ворот.

Рисунок В.2 – example_obstacle_lane (скриншот при оформлении).


4. Пример 3 — Навигационная трасса

Файл: example_navigation_track.mur_scene

Назначение: движение между линиями разметки, зоны старта/финиша, буй как ориентир.

Состав:

Две параллельные линии разметки.
Зона старта — зелёная плоскость на дне.
Зона финиша — красная плоскость на дне.
Буй — сфера на ножке в центре.

Типовое задание: старт из зелёной зоны, движение между линиями, финиш в красной; буй — промежуточная точка.

Рисунок В.3 – example_navigation_track (скриншот при оформлении).


5. Сводная таблица примеров

№ 1. example_markers_course — Markers, Navigation — маршрут по цветам.
№ 2. example_obstacle_lane — Obstacles — маневрирование.
№ 3. example_navigation_track — Navigation — следование разметке.


6. Расширение полигонов

Для своего полигона обычно берут ближайший пример, сохраняют копию сцены в редакторе или собирают новую из файлов Markers/, Obstacles/ и других папок, затем проверяют сцену в симуляторе с MiddleAUV.

Файлы: KURS2/MUR_Object_Library/Examples/.
