# Таблица рекомендуемых цветов и размеров

## Цветовое кодирование (п. 2.4 ТЗ)

| Цвет | Материал в сцене | Назначение |
|------|------------------|------------|
| Красный | `Materials/Objects/Colors/Red.xml` | Старт, опасность, запрет |
| Зелёный | `Materials/Objects/Colors/Green.xml` | Финиш, цель, разрешение |
| Жёлтый | `Materials/Objects/Colors/Yellow.xml` | Промежуточные точки, указатели |
| Синий | `Materials/Objects/Colors/Blue.xml` | Промежуточные точки |
| Оранжевый | `Materials/Objects/Colors/Orange.xml` | Промежуточные точки, балки |
| Фиолетовый | `Materials/Objects/Colors/Magenta.xml` | Промежуточные точки |
| Белый/нейтральный | `Materials/Objects/Generic.xml` | Навигационные линии |
| Серый/чёрный | `Materials/Objects/Colors/Black.xml` | Камни, фон |
| Циан | `Materials/Objects/Colors/Cyan.xml` | Буи, акценты |

**Под водой:** для глубоких маркеров предпочтительны жёлтый и белый (красный быстро «гаснет»).

## Рекомендуемые размеры

| Тип объекта | Размер | Комментарий |
|-------------|--------|-------------|
| Маркер старта/финиша | 0.5 м | Заметен на фоне AUV (0.5 м) |
| Промежуточный маркер | Ø0.35 м, h0.5 м | |
| Препятствие-стойка | h1.5–2.5 м | Выше аппарата |
| Ворота | проём 1.5–2.0 м | Шире AUV |
| Стрелка | осн. 1.0×0.2×0.1 м, нак. 0.4×0.4×0.1 м | По ТЗ п. 2.3 |
| Цифра | h1.0 м, линия 0.1 м | По ТЗ п. 2.3 |
| Линия трассы | 6×0.03×0.15 м | Тонкий параллелепипед |
