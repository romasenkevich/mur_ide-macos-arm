# Приложение А. Каталог объектов библиотеки

Масштаб сцен: **1:10…1:20** (MiddleAUV ≈ 0.5×0.5×0.3 м).  
Файлы: `ИмяПапки/имя_файла.mur_scene`

## Markers — маркеры и указатели

| Файл | Описание | Форма | Цвет | Размер (м) |
|------|----------|-------|------|------------|
| `marker_start_red` | Стартовый маркер | Куб | Красный | 0.5³ |
| `marker_finish_green` | Финишный маркер | Сфера | Зелёный | Ø0.5 |
| `marker_waypoint_yellow` | Промежуточная точка | Цилиндр | Жёлтый | Ø0.35, h0.5 |
| `marker_waypoint_blue` | Промежуточная точка | Цилиндр | Синий | Ø0.35, h0.5 |
| `marker_waypoint_orange` | Промежуточная точка | Цилиндр | Оранжевый | Ø0.35, h0.5 |
| `marker_waypoint_purple` | Промежуточная точка | Цилиндр | Фиолетовый | Ø0.35, h0.5 |
| `marker_direction_arrow` | Указатель направления | 2 параллелепипеда | Жёлтый | осн. 1.0×0.2×0.1, нак. 0.4×0.4×0.1 |
| `marker_depth_pole` | Маркер глубины | Стойка + 3 перекладины | Циан/красн./жёлт./зел. | высота ~2 м |

## Obstacles — препятствия

| Файл | Описание | Размер (м) |
|------|----------|------------|
| `obstacle_pole_red` | Вертикальная стойка | Ø0.2, h2.5 |
| `obstacle_beam_horizontal` | Горизонтальная балка | 3.0×0.25×0.25 |
| `obstacle_gate` | Ворота (2 стойки + перекладина) | проём ~2.5 м |
| `obstacle_corner_L` | Угол Г-образный | 2×0.2 м |
| `obstacle_maze_walls` | Фрагмент лабиринта (4 стены) | h~1.8 |

## Navigation — навигация

| Файл | Описание |
|------|----------|
| `nav_track_line_white` | Линия разметки трассы (белая/серая) |
| `nav_zone_start` | Зона старта (плоскость, зелёная) |
| `nav_zone_finish` | Зона финиша (плоскость, красная) |
| `nav_digit_1` | Цифра 1 для нумерации |
| `nav_buoy` | Буй (сфера на ножке) |
