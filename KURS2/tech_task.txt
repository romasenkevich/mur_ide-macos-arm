Тема 9: Создание библиотеки простых 3D-объектов для учебных сцен в симуляторе MUR IDE
Рекомендация по уточнению темы (до 12 слов):
Библиотека простых 3D-объектов для создания учебных сцен в симуляторе MUR IDE
Сыч Алексей Дмитриевич

1. Исходные данные к проекту
1.1. Цель работы
Создание библиотеки простых 3D-объектов (маркеров, препятствий, элементов навигационной разметки) с использованием редактора сцен MUR IDE, предназначенной для быстрого конструирования учебных полигонов и отработки базовых навыков управления автономным необитаемым подводным аппаратом (АНПА).
1.2. Общие требования
Библиотека создается с использованием встроенного редактора сцен, входящего в состав симулятора MUR IDE. Каждый объект должен сохраняться как отдельный файл сцены или как группа объектов для последующего копирования в новые сцены. Объекты должны иметь простую геометрическую форму (кубы, сферы, цилиндры, конусы) и быть понятными для начинающих пользователей. К каждому объекту прилагается краткое описание: назначение, рекомендуемые цвета и размеры. Библиотека должна включать не менее 12-15 различных объектов, сгруппированных по функциональному назначению. Все объекты должны быть протестированы в симуляторе на видимость и корректное отображение.
1.3. Функциональные требования
Группа Маркеры и указатели:
Стартовый маркер в виде красного куба или сферы размером примерно 0.5 метра. Финишный маркер в виде зеленого куба или сферы аналогичного размера. Промежуточные маркеры трех-четырех цветов (желтый, синий, оранжевый, фиолетовый) в форме цилиндров или кубов. Указатели направления в виде стрелок, собранных из двух параллелепипедов (основание и наконечник). Маркеры глубины в виде вертикальных шестов с поперечными элементами разного цвета на разных уровнях.
Группа Препятствия:
Вертикальная стойка в виде высокого цилиндра красного цвета высотой 2-3 метра. Горизонтальное препятствие в виде длинного параллелепипеда, имитирующего трубу или балку. Арка или ворота, состоящие из двух вертикальных стоек и горизонтальной перекладины. Угловое препятствие в виде Г-образной конструкции из двух параллелепипедов. Лабиринт в виде нескольких вертикальных стен, расположенных под углом друг к другу.
Группа Навигационные элементы:
Линии разметки в виде тонких длинных параллелепипедов (белого или желтого цвета) для обозначения трасс. Зоны в виде плоских квадратов с полупрозрачной текстурой для обозначения старта и финиша. Цифры для нумерации маркеров, собранные из тонких параллелепипедов. Подводные буи в виде сферы на тонкой ножке для обозначения точек интереса.
Группа Элементы рельефа и фона:
Камни разных размеров в виде полусфер или деформированных сфер серого и коричневого цвета. Простая растительность в виде зеленых конусов и цилиндров. Модели трубопровода в виде длинных цилиндров с изгибами под 45 и 90 градусов.
Группа Составные объекты для комплексных заданий:
Модель мостовой опоры из нескольких параллелепипедов. Упрощенная модель затонувшего объекта в виде куба с прикрепленными цилиндрами. Трасса с воротами и маркерами как готовый фрагмент полигона.
Требования к документации:
Каталог объектов с изображениями и описанием каждого объекта. Таблица рекомендуемых цветов и размеров. Инструкция по импорту объектов в новые сцены. Примеры использования объектов для сборки типовых учебных заданий.

2. Содержание расчетно-пояснительной записки
Введение
Значение стандартизированных библиотек объектов для ускорения разработки учебных сцен в симуляторах подводной робототехники. Обзор возможностей редактора сцен MUR IDE для создания и сохранения пользовательских объектов. Цель и задачи работы.
1. Анализ требований к библиотеке объектов
1.1. Типовые элементы учебных сцен для отработки навыков управления АНПА: навигационные маркеры, препятствия, элементы разметки.
1.2. Анализ существующих объектов в базовой поставке MUR IDE и определение потребности в дополнительных элементах.
1.3. Определение номенклатуры объектов библиотеки и их функционального назначения.
1.4. Выбор цветовой гаммы для различных типов объектов с учетом видимости в подводной среде.
1.5. Определение оптимальных размеров объектов для масштаба сцен (рекомендуемый масштаб 1:10 или 1:20).
2. Проектирование библиотеки объектов
2.1. Разработка классификации объектов по функциональным группам: маркеры, препятствия, навигация, рельеф, составные объекты.
2.2. Проектирование простых объектов:
•	Эскизы и размеры для кубов, сфер, цилиндров различных цветов.
•	Определение соотношений размеров для составных объектов (стрелки, ворота, цифры).
2.3. Проектирование составных объектов:
•	Стрелка-указатель: основание 1.0×0.2×0.1 м, наконечник 0.4×0.4×0.1 м.
•	Ворота: стойки высотой 2.0 м, диаметр 0.2 м, перекладина длиной 2.5 м.
•	Цифры: высота 1.0 м, толщина линий 0.1 м.
2.4. Разработка системы цветового кодирования:
•	Красный: опасность, запрет, старт.
•	Зеленый: цель, финиш, разрешение.
•	Желтый/синий: промежуточные точки.
•	Белый: навигационные элементы.
•	Серый/коричневый: элементы рельефа.
3. Реализация библиотеки объектов
3.1. Знакомство с интерфейсом редактора сцен MUR IDE:
•	Панель инструментов для создания и редактирования объектов.
•	Работа с библиотекой примитивов.
•	Группировка объектов и сохранение в файл.
3.2. Создание простых объектов:
•	Кубы разных цветов (красный, зеленый, желтый, синий).
•	Сферы разных цветов.
•	Цилиндры разных цветов и пропорций (высокие стойки, низкие маркеры).
3.3. Создание составных объектов:
•	Стрелка-указатель из двух параллелепипедов.
•	Ворота из двух цилиндров и одного параллелепипеда с группировкой.
•	Цифры от 0 до 9 из параллелепипедов.
•	Глубинный маркер из вертикального цилиндра и горизонтальных элементов.
3.4. Создание элементов рельефа:
•	Камни из полусфер с измененной геометрией.
•	Растительность из зеленых конусов.
3.5. Создание составных сцен-примеров:
•	Фрагмент трассы с последовательностью маркеров.
•	Участок с препятствиями.
3.6. Сохранение объектов:
•	Каждый объект сохраняется как отдельный файл сцены с понятным именем.
•	Создание папок по группам для удобства навигации.
3.7. Документирование библиотеки:
•	Создание каталога с изображениями объектов (скриншоты).
•	Описание каждого объекта с указанием размеров и цветов.
•	Инструкция по импорту объектов в новые сцены.
4. Тестирование и апробация библиотеки
4.1. Загрузка каждого объекта в симулятор для проверки видимости и корректности отображения.
4.2. Создание тестовой сцены с использованием нескольких объектов из разных групп.
4.3. Запуск аппарата в тестовой сцене и проверка взаимодействия с объектами.
4.4. Оценка читаемости и узнаваемости объектов с различных ракурсов и расстояний.
4.5. Корректировка размеров и цветов при необходимости.
Заключение
Состав созданной библиотеки (количество объектов, группы). Возможности использования библиотеки для ускоренной разработки учебных сцен. Рекомендации по пополнению и развитию библиотеки. Направления дальнейшего развития (добавление текстурированных объектов, объектов с простой анимацией).

Дополнительные рекомендации студенту
Инструменты и ресурсы:
Среда разработки MUR IDE с установленным редактором сцен доступна для скачивания на сайте murproject.com. Редактор сцен содержит библиотеку примитивов (кубы, сферы, цилиндры, конусы, плоскости) и инструменты для их трансформации (перемещение, масштабирование, вращение). Для создания составных объектов используется функция группировки.
Пошаговая инструкция для начинающих:
Шаг 1. Изучение редактора. Откройте редактор сцен, создайте новый проект. Добавьте несколько примитивов, поэкспериментируйте с изменением их размеров, цвета и положения. Научитесь вращать камеру для просмотра объекта с разных сторон.
Шаг 2. Создание простых объектов. Для каждого цвета создайте отдельные объекты: красный куб, зеленую сферу, желтый цилиндр. Сохраняйте каждый объект в отдельный файл с понятным именем.
Шаг 3. Создание составных объектов. Начните со стрелки: создайте длинный параллелепипед (основание), затем маленький параллелепипед в форме треугольника (наконечник). Выделите оба объекта и сгруппируйте. Сохраните как единый объект.
Шаг 4. Создание ворот. Создайте два высоких цилиндра (стойки), расположите их параллельно на расстоянии примерно 2 метра. Создайте длинный параллелепипед (перекладину), поместите его сверху на стойки. Сгруппируйте все три объекта.
Шаг 5. Создание цифр. Для каждой цифры используйте тонкие параллелепипеды. Начните с простой цифры 1 (один вертикальный элемент). Постепенно усложняйте.
Шаг 6. Систематизация. Создайте на диске папку "MUR_Object_Library". Внутри создайте подпапки "Markers", "Obstacles", "Navigation", "Terrain", "Examples". Сохраняйте объекты в соответствующие папки.
Шаг 7. Документирование. Для каждого объекта сделайте скриншот в редакторе. В текстовом файле опишите объект: название, размеры, цвета, назначение.
Рекомендации по выбору размеров:
Учитывайте, что аппарат MiddleAUV имеет размеры примерно 0.5×0.5×0.3 метра. Маркеры должны быть заметны, поэтому рекомендуемый размер 0.5-1.0 метр. Препятствия должны быть выше аппарата (1.5-2.0 метра). Ворота должны быть шире аппарата (ширина проема 1.5-2.0 метра).
Советы по цветовому оформлению:
Используйте насыщенные, яркие цвета, так как под водой цвета становятся менее насыщенными. Красный цвет на глубине быстро теряет яркость, поэтому для глубоководных маркеров лучше использовать желтый или белый. Для контраста с фоном дна выбирайте цвета, отличные от серого и коричневого.
Ожидаемые результаты:
Готовая библиотека из 12-15 объектов, организованных по папкам. Каталог объектов с изображениями и описаниями. Инструкция по использованию. 2-3 примера учебных сцен, собранных из объектов библиотеки. Все материалы предоставляются в электронном виде вместе с пояснительной запиской.
